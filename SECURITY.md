# Security Policy

## Supported versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

Older versions are not supported. Please update to the latest 0.1.x release.

## Reporting a vulnerability

Please do not report security issues in public issues or discussions.

Instead, report them privately through GitHub's "Report a vulnerability" feature:

https://github.com/nabrahma/Swayfield/security/advisories/new

I aim to reply within 7 days. Please include the Blender version, the Swayfield version, and steps to reproduce the problem if you can.

## Scope

Swayfield makes no network calls and has no dependencies outside Blender. Issues that involve loading untrusted `.blend` files or add-on data are welcome reports.
